# Project Folder Structure

This document gives a quick overview of the project structure and what each main file/folder is responsible for. Empty files are marked as “Currently empty”.

## Root structure

```text
appointment-booking-system/
├── README.md
├── backend/
├── database/
├── docs/
├── frontend/
├── tests/
└── .gitignore
```

### Root files

- `README.md` — Project overview and setup guidance for the appointment booking system.
- `.gitignore` — Git ignore rules for local environment and build artifacts.

### Backend file breakdown

- `.env` — Local environment variables for the backend, including secrets and DB configuration.
- `.gitignore` — Ignores local generated data and dependency folders for backend.
- `package.json` — Backend dependencies, scripts, and project metadata.
- `pnpm-lock.yaml` — Lockfile generated by pnpm for dependency consistency.
- `pnpm-workspace.yaml` — Workspace configuration for pnpm package management.
- `prisma.config.ts` — Prisma runtime configuration for the project.
- `skills-lock.json` — Internal tooling lock file used by the development environment.
- `tsconfig.json` — TypeScript compiler settings for the backend.

#### `prisma/`

- `schema.prisma` — Main Prisma schema defining the database models, relations, and enums.
- `migrations/20260910105136_initial_schema/migration.sql` — Initial database migration created from the Prisma schema.

#### `src/`

- `seed.ts` — Database seed script used to populate sample data for development/testing.
- `server.ts` — Starts the Express API and wires the app routes.
- `vite-env.d.ts` — Type declarations for Vite environment variables.

#### `src/controllers/`

- `auth.controller.ts` — Handles user registration, login, token creation, and account-related API logic.
- `business.controller.ts` — Business-specific operations and endpoints.
- `customer.controller.ts` — Customer-specific controller logic.
- `provider.controller.ts` — Provider dashboard and provider-related request handling.

#### `src/generated/prisma/`

- `browser.ts` — Generated browser-side Prisma client for frontend-safe usage patterns.
- `client.ts` — Generated Prisma client runtime used by the backend.
- `commonInputTypes.ts` — Shared Prisma input types generated from the schema.
- `enums.ts` — Prisma enums generated for the schema.
- `models.ts` — Generated model type declarations.
- `models/` — Folder containing generated Prisma model definitions and related helpers.

#### `src/lib/`

- `prisma.ts` — Singleton Prisma client instance used across the backend.

#### `src/middleware/`

- `auth.middleware.ts` — JWT/auth middleware for protecting routes and checking user roles.

#### `src/routes/`

- `auth.routes.ts` — Authentication endpoints such as register/login and profile access.
- `business.routes.ts` — Routes for business-related API endpoints.
- `customer.routes.ts` — Routes for customer-related API endpoints.
- `provider.routes.ts` — Routes for provider-related API endpoints.

#### `src/services/`

- `api.ts` — Shared API helper for making HTTP requests and handling API errors; currently contains the base request logic.
- `availability.service.ts` — Handles appointment availability logic and schedule calculations.
- `booking.service.ts` — Currently empty.
- `provider.service.ts` — Provider-related business logic such as listing, filtering, and appointment-related tasks.
- `subscription.service.ts` — Manages subscriptions and plan-related functionality.

### Frontend file breakdown

- `.gitignore` — Ignores generated files and editor artifacts for the frontend.
- `eslint.config.js` — ESLint rules and configuration for the frontend codebase.
- `index.html` — Main HTML entry point used by Vite.
- `package.json` — Frontend package metadata, scripts, and dependencies.
- `pnpm-lock.yaml` — Dependency lock file for frontend packages.
- `README.md` — Frontend-specific setup and usage notes.
- `tsconfig.app.json` — App-specific TypeScript configuration.
- `tsconfig.json` — Root TypeScript config for the frontend.
- `tsconfig.node.json` — TypeScript config for Node/Vite tooling.
- `vite.config.ts` — Vite build and dev server configuration.

#### `src/`

- `App.css` — Global styling for the main app shell.
- `App.tsx` — Root React component that renders the app and toast notifications.
- `index.css` — Global CSS and base styles.
- `main.tsx` — App bootstrap and router setup.
- `assets/` — Static assets such as images, logos, icons, and fonts.

#### `src/components/`

- `booking/` — Booking flow UI such as confirmation, summary, and slot selection.
- `calendar/` — Calendar components for schedule display.
- `dashboard/` — dashboard widgets and dashboard UI blocks.
- `forms/` — Reusable form components.
- `home/` — Homepage-specific components.
- `layout/` — Shared layout and navigation components.
- `ui/` — Reusable UI building blocks.

#### `src/context/`

- `AuthContext.tsx` — Auth context and global login state management.

#### `src/data/`

- `providers.ts` — Seed/mock provider data or static provider list data.

#### `src/hooks/`

- `useAuth.ts` — Hook for auth actions and session state.
- `useAvailability.ts` — Hook for retrieving and managing availability data.
- `useBookings.ts` — Hook for booking operations and booking state.

#### `src/layouts/`

- `AdminLayout.tsx` — Admin dashboard shell layout.
- `BusinessLayout.tsx` — Business dashboard layout.
- `CustomerLayout.tsx` — Customer dashboard layout.
- `ProviderLayout.tsx` — Provider dashboard layout.
- `PublicLayout.tsx` — Public-facing site layout.
- `StaffLayout.tsx` — Staff dashboard layout.

#### `src/lib/`

- This folder is present but currently empty.

#### `src/pages/`

- `dashboard/` — Dashboard pages for customer, provider, business, and staff roles.
- `public/` — Public pages like home, pricing, login, and registration.
- `staff/` — Staff-specific views and management pages.

#### `src/routes/`

- `AppRoutes.tsx` — Central route configuration for the frontend application.
- `ProtectedRoute.tsx` — Route guard for authenticated users.
- `RoleRoute.tsx` — Route guard for role-specific access control.

#### `src/services/`

- `api.ts` — Frontend API helper for HTTP requests to the backend; currently empty.
- `auth.ts` — Authentication service functions.
- `bookings.ts` — Booking-related API call wrappers.
- `providers.ts` — Provider listing and lookup service calls.
- `subscriptions.ts` — Subscription service calls.

#### `src/types/`

- `index.ts` — Shared TypeScript interfaces and type definitions for the frontend.
